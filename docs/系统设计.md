# 系统设计

## 架构概览

系统分为前端、后端、服务层与数据目录。

- 前端：React + Vite 单页应用。
- 后端：FastAPI 提供 REST API。
- 服务层：解析、图谱构建、合并、RAG、对话、报告生成按模块拆分。
- 数据目录：`backend/data/` 用于存放上传文件、解析中间结果和后续缓存。

## 后端模块

| 模块 | 文件 | 当前职责 |
| --- | --- | --- |
| 上传 | `backend/main.py` | 保存上传文件 |
| 解析 | `backend/services/parser.py` | 返回教材解析占位结果 |
| 图谱 | `backend/services/graph_builder.py` | 返回示例知识图谱 |
| 合并 | `backend/services/merger.py` | 返回跨教材合并占位决策 |
| RAG | `backend/services/rag.py` | 返回检索占位片段 |
| 对话 | `backend/services/chat.py` | 返回教师反馈占位回复 |
| 报告 | `backend/services/report.py` | 返回报告大纲 |

## 前端布局

前端采用三栏布局：

- 左侧：教材管理与解析、合并入口。
- 中间：知识图谱画布。
- 右侧：合并、检索、对话、报告 Tab 面板。
