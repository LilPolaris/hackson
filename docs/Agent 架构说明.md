# Agent 架构说明

## Agent 角色

系统后续可以拆分为多个协作 Agent：

1. Parser Agent：负责教材解析、章节识别与内容切块。
2. Graph Agent：负责抽取知识点、关系与图谱结构。
3. Merge Agent：负责跨教材去重、互补与冲突检测。
4. RAG Agent：负责根据问题检索教材片段与图谱上下文。
5. Teacher Loop Agent：负责接收教师反馈并优化整合策略。
6. Report Agent：负责生成最终整合报告。

## 数据流

教材上传后进入解析流程，解析结果进入图谱构建流程。多本教材的图谱经过合并模块处理后，提供给 RAG、对话和报告生成模块使用。

## 当前实现状态

当前版本只保留模块边界和接口形态，方便比赛过程中快速替换为真实实现。
